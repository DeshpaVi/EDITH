# Voice authentication POC: architecture

Region **us-east-1**. Scope: consenting voices only. Voice is one factor, not the gate.
Diagram: `architecture.svg` / `architecture.png` (generated by `make_diagram.py`).

## How a verification call works

1. The caller dials the test number; the contact flow `APFM_Auth_Flow` starts.
2. The flow plays the consent notice and starts **live media streaming** (customer audio only) into Kinesis Video Streams.
3. The **Lex V2 bot** asks for name and address. Its only job is to keep the caller speaking; the words are not scored.
4. The flow invokes Lambda **`voice-auth-poc-verify:live`** (synchronous, 8 s limit) with `kvsArn`, `kvsFragment`, `speakerId`.
5. The Lambda reads the most recent ~18 s of caller audio from Kinesis Video Streams (`GetMedia`).
6. It loads the enrolled voiceprint (DynamoDB) and the thresholds (SSM Parameter Store).
7. It trims silence, computes an ECAPA-TDNN embedding, takes the cosine similarity, chooses a band, and writes an audit row (score and decision only).
8. It returns `voiceDecision` (`authenticated` / `inconclusive` / `failed`) plus `voiceScore`, `voiceReason`, `voiceDetail`; the flow branches on it.

## Services and what each one does

| Service | Resource | Role | Managed by |
|---|---|---|---|
| Amazon Connect | existing instance, flow `APFM_Auth_Flow` | Telephony, consent prompt, streaming start, branching on the decision | Console / flow JSON (`connect/APFM_Auth_Flow.json`) |
| Amazon Connect live media streaming | existing config, prefix `vmail-connect-win-demo-manual-contact-` | Sends customer audio to Kinesis Video Streams (1 h retention, key `aws/kinesisvideo`) | Pre-existing; not changed |
| Amazon Kinesis Video Streams | one stream per contact (created by Connect) | Buffers live caller audio so the Lambda can read it after the caller has spoken | Connect |
| Amazon Lex V2 | bot `APFM_Auth_Bot`, alias `TestBotAlias` | Prompts the caller so they speak continuously; content not scored | Console |
| AWS Lambda | `voice-auth-poc-verify` (alias `live`) | Reads audio, embeds, compares, decides, audits. Container image, 3008 MB, provisioned concurrency 1, model preloaded at init | `02-compute-connect.yaml` |
| AWS Lambda | `voice-auth-poc-enrol` | Enrols (average of clips into one voiceprint), scores test clips, deletes a voiceprint. 300 s timeout | `02-compute-connect.yaml` |
| Amazon ECR | `voice-auth-poc/scorer` | Holds the container image (SpeechBrain ECAPA-TDNN baked in) | `01-foundation.yaml` |
| AWS CodeBuild | `voice-auth-poc-image-build` | Builds and pushes the image; prints the image digest | `03-image-build.yaml` |
| Amazon S3 | enrolment bucket | Enrolment clips under `enrol/<speakerId>/`. SSE-KMS, 30-day lifecycle, no versioning, public access blocked, TLS only | `01-foundation.yaml` |
| Amazon S3 | build-source bucket | Holds `source.zip` for CodeBuild | `03-image-build.yaml` |
| Amazon DynamoDB | `voice-auth-poc-voiceprints` | speakerId to 192-d embedding, consent reference, retention. KMS, TTL `expiresAt`, point-in-time recovery off | `01-foundation.yaml` |
| Amazon DynamoDB | `voice-auth-poc-verification-log` | Audit rows: contactId, score, decision, reason, detail. No audio, no embeddings. TTL | `01-foundation.yaml` |
| AWS Systems Manager Parameter Store | `/voice-auth-poc/threshold/high`, `/low` | Decision thresholds, editable without redeploying | `01-foundation.yaml` |
| AWS KMS | customer-managed key `alias/voice-auth-poc-data` | Encrypts the enrolment bucket, both tables and the ECR repository | `01-foundation.yaml` |
| Amazon CloudWatch Logs | `/aws/lambda/voice-auth-poc-*`, CodeBuild logs | Operational logs, 30-day retention. Scores and decisions only | `02` and `03` stacks |
| AWS IAM | one role per function plus the build role | Least privilege (verify is read-only on voiceprints, append-only on the log) | `02` and `03` stacks |
| AWS CloudFormation | `voice-auth-poc-foundation`, `-compute`, `-image-build` | Infrastructure as code for everything above except Connect, Lex and the flow | Console upload |

## Not built (deliberately)

- **Anti-spoofing / replay detection.** A recording of the enrolled voice will likely pass. This is why voice is a factor, not the gate.
- **Step-up factor** (SMS one-time code or agent verification) for the inconclusive band.
- **SageMaker endpoint.** A warm Lambda (provisioned concurrency plus model preload) is used instead.
- **Amazon Transcribe** liveness check.
- **Connect, Lex and the flow in CloudFormation.** Built in the console; the flow is exported to `connect/APFM_Auth_Flow.json`.

## Data handling

- No customer audio is used; enrolled voices are consenting people only.
- Speaker IDs are pseudonymous (`spk_...`); no names or phone numbers are used as keys.
- Audio and embeddings are never logged; logs carry scores, decisions and durations.
- Retention is set on day one (30 days): S3 lifecycle, DynamoDB TTL and log-group retention.
- Deletion path: enrol function `mode: delete` removes the voiceprint and that speaker's audio.
- The consent line in the flow ("recorded and monitored for quality and training") does **not** cover creating a voiceprint; real callers would need explicit biometric consent and legal review.
